# AI HR Recruitment Assistant

The AI HR Recruitment Assistant is an AI-based application designed to support the recruitment process by analyzing candidate resumes and identifying relevant skills.

The system compares candidate skills with the required skills for a selected job role, generates a candidate matching score, and provides a recommendation based on the matching result.

## Key Features
- Resume Analysis
- Skill Extraction
- Job Requirement Matching
- Candidate Match Score
- Candidate Recommendation

## Technologies Used
- Python
- HTML
- CSS
- Artificial Intelligence / Machine Learning
